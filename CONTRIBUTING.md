# Contributions and releases

This source-only project uses MIT with HolySong0817 attribution. No operational or signed release is provided. Do not submit confidential code or material you cannot license.

Contributors must have authority to provide their changes under MIT and identify any third-party material and required notices. Source-only publication does not approve release artifacts, audio redistribution or signing-service integration.

Preserve the fixed warning text, ordered playback evidence, 2000 ms minimum and fail-closed behavior. Never replace failure with an unprotected control path. Changes to build inputs, asset pins, hook scope or release gates require review and meaningful negative tests.

No signing secrets belong in the repository. Establish repository/signing roles and MFA only after the owner's approval and the provider's verified free terms. Release requests need human review; no remote signing integration is currently configured.
